# Security policy

Tinta PDF opens files that come from anywhere, so a crafted document that crashes it, runs code,
reads files it should not, or makes it reach the network is a security problem.

## Reporting a vulnerability

Write to **hola@tintaoffice.com** with the version (Help > About), the operating system and,
if you can, a small file that shows the problem. Please do not open a public issue first.

You will get an answer within 7 days. When the problem is confirmed, the fix ships in the next
release and the release notes credit you unless you ask otherwise. Problems that also affect
PdfCraft are reported to its maintainers too (https://github.com/storytold/pdfcraft).

## Supported versions

Only the latest release published on https://tintaoffice.com gets security fixes.
